About ApocaLab

ApocaLab is a prototype for accessible, source-conscious scientific education. The current version demonstrates a clickable map, geographic reference measurements, a shareable view and an artistic animated cloud.

Accuracy over spectacle

Visual design can make an educational topic approachable, but it must not pretend to be an evidence-backed physical model. Every numerical field in this preview is labeled according to what it actually measures.

Project status

This website is a product-review demonstration, not a public safety service or a completed research tool. It is published for interface and technical feasibility discussions only.
